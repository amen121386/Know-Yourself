# 可选规则模块：部署反哺自动同步规范 (Auto-Sync to Life OS)

> 模块状态：[可选插件式加载]  
> 适用场景：用户希望 AI Agent 在帮自己部署、编写新工具或添加新技能后，自动在本地知识库做资产登记。

---

## 触发与执行机制

### 1. 触发条件
当 Agent 成功在宿主机器上完成以下操作之一并实测跑通：
- 部署了新的开源软件 / 本地服务 / CLI 工具
- 安装或编写了新的 AI Skill / Prompt / 工作流脚本

### 2. 同步写入目标
在宿主的知识库指定路径进行自动追加记录：
- **项目/工具部署** → 追加至 `<VAULT_PATH>/03_RESOURCES/AI/AI_TOOLS.md`  
  *（需包含：工具名、版本、绝对路径/端口、核心命令、主要用途、[FACT] 标记、日期）*
- **Skill 技能安装** → 追加至 `<VAULT_PATH>/03_RESOURCES/AI/SKILLS.md`  
  *（需包含：技能名、类型、作用、实测状态、日期）*

### 3. 安全与幂等性保障
- 仅向当前激活的“活系统”写入，严禁修改或写入历史快照目录。
- 写入前检查是否已存在同名记录；若已存在，仅更新版本号与更新日期，避免重复冗余。
