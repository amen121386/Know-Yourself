# 数据安全与防泄漏指南 (Privacy & Safe Practice)

> “真正的知识不仅在于知晓何物，更在于知晓边界。”

当你开始使用并可能二次将此系统维护在 Git/GitHub 上时，请务必建立以下安全反射：

---

## 1. 永不触碰的红线
- **绝不提交 API 密钥**：所有涉及大模型、云服务、第三方平台的 Secret，只能写在本地 `.env` 中，且必须确认 `.gitignore` 包含 `*.env`。
- **Obsidian 插件隐私黑洞**：部分三方同步插件（如 WebDAV、S3、LiveSync）会将服务器密码明文写在 `.obsidian/plugins/.../data.json` 中。本项目预置的 `.gitignore` 已拦截此目录，切勿强行将其提交到公共仓库。
- **真实资产与身份信息隔离**：
  - 真实的银行账户、体检病历、家人住址、未公开的商业方案，请勿放置在打算公开分享的仓库中。

---

## 2. 检查清单（对外 Push 前的自检）
- [ ] 运行 `git status`，确认没有意外暂存 `.env` 或带有私人密码的 JSON。
- [ ] 确认没有硬编码本地内网 IP 或真实家庭网络拓扑。
- [ ] 如果要基于本项目创建公共模板，请确保所有个人日记已清空。
