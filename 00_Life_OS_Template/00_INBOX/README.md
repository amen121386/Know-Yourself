# 00_INBOX (灵感与临时抓取池)

> “未经审视的人生不值得过。” —— 苏格拉底

### 核心定位
- **零思考倾倒点**：无论是临时看到的文章片段、突发灵感、待处理的杂事，第一时间丢入此目录。
- **定期归零（Inbox Zero）**：每周或每日固定时间，对 INBOX 进行清空分流：
  - 属于当前具有明确截止日期与交付目标的任务 → 移入 `01_PROJECTS`
  - 属于长期需要维护的生活/工作领域 → 移入 `02_AREAS`
  - 属于未来可能查阅的参考资料或工具 → 移入 `03_RESOURCES`
  - 毫无价值或已解决的琐事 → 直接删除或归入 `04_ARCHIVE`
