# 02_AREAS (长期关注领域)

### 核心定位
- **长青责任区（没有终点的持续投入）**：与有明确截止日期的 `01_PROJECTS` 不同，这里存放需要长期维护、维持某种标准的生活与心智领域。
- **经典领域推荐**：
  - `Health_and_Body.md`（身体能量、睡眠、运动）
  - `Mind_and_Philosophy.md`（心智认知、哲学审视、情绪自省）
  - `Finance_and_Wealth.md`（资产规划原则、消费哲学）
  - `Career_and_Craft.md`（职业技能、工程技艺、工作流进阶）
  - `Relationships.md`（重要人脉原则、家庭与朋友的陪伴边界）
