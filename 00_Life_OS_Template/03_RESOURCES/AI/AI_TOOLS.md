## 规范格式定义
每条记录字段说明：
- **工具名称**：官方规范名称
- **版本**：实测运行时的确切 Release 版本
- **部署绝对路径 / 端口**：可直接调用的执行路径或本地 Web 服务端口

- **实测状态**：必须包含 `[FACT]` 标签及通过状态
- **验证/更新日期**：YYYY-MM-DD
