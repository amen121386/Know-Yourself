# Protocol 04: 记忆蒸馏与“活到老学到老”进化协议 (Memory Distillation Pipeline)

## 核心目标
本地外接大脑的“进化”绝不等于历史文件的无限堆积。本协议负责将已完成复盘的离散决策事件，蒸馏提炼为高密度的**个体元认知规律**，从而实现“活到老，学到老”。

## 蒸馏与归档标准流水线

1. **事后真伪审计（Truth vs. Luck Separation）**
   * 读取已到达 `Review_Date` 的 `L2_decisions/PDR-*.md` 文件。
   * 将用户汇报的“现实客观结果”与事前锁定的 `Core_Assumptions`（核心假设）逐条比对，将结果严格归入以下四象限之一：
     * **A. 逻辑正确 + 结果成功（真认知能力）**：固化为可复用的方法论。
     * **B. 逻辑正确 + 结果失败（小概率黑天鹅干扰）**：接纳合理损耗，不因坏结果否定正确的决策框架。
     * **C. 逻辑错误 + 结果侥幸成功（危险的狗屎运）**：**最高级别警报！** 严厉指出其中的侥幸成分，防止用户将运气内化为盲目自信。
     * **D. 逻辑错误 + 结果失败（认知盲区暴露）**：精准定位当初是受哪种情绪或信息差误导。
2. **更新认知偏差注册表（Bias Registry Update）**
   * 从 C 象限与 D 象限的复盘中，提炼出一句高度凝练的“个人防坑定律”（例如：`[偏差编号 B-04] 当处于高强度备考或工作焦虑期时，极易高估自己同时开启新副业的时间承载力，需强制打五折计算可用工时`），追加写入 `vault/L1_atlas/bias_registry.md`。
3. **冷数据归档与索引迁移**
   * 将完成复盘填充后的 `PDR-*.md` 文件从 `vault/L2_decisions/` 移动至 `vault/L3_archive/`。
   * 将 `vault/brain_index.json` 中对应条目的 `status` 更新为 `validated`（假设证实）或 `falsified`（假设证伪），确保 L2 温记忆区始终保持轻量、聚焦。
